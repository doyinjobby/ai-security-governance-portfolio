## 1. Portfolio Overview

This repository demonstrates practical approaches to AI security, governance, risk management, security testing and assurance.

It focuses on helping organisations adopt AI securely and responsibly through risk-based governance, technical security controls, continuous assurance and human oversight.

**Guiding Principle: Protect to Enable**

## 5. Assurance Approach

The portfolio follows a continuous assurance lifecycle:

**GOVERN → MAP → MEASURE → MANAGE → MONITOR → REASSESS**

The NIST AI RMF functions are iterative and interconnected. Monitoring and reassessment support their continued application throughout the AI system lifecycle.
